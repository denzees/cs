1.1 Number systems

Computers contain millions of tiny switches that are either ON (1) or OFF (0). That is why all data (numbers, text, sound, images) must be converted to binary before a computer can process it.

SystemBaseDigitsColumn headings (right to left)
Denary100–91, 10, 100, 1000 …
Binary20, 11, 2, 4, 8, 16, 32, 64, 128 …
Hexadecimal160–9, A–F (A=10 … F=15)1, 16, 256, 4096 …
Converter (type in any box):
Binary → denary

Add the column value for every 1. Example: 11101110 = 128 + 64 + 32 + 8 + 4 + 2 = 238. Works for any length (e.g. 12-bit or 16-bit).

Denary → binary (two methods)

Method 1, subtract powers of 2: 142 − 128 = 14; 14 − 8 = 6; 6 − 4 = 2; 2 − 2 = 0 → 1000 1110.

Method 2, divide by 2: keep dividing by 2 and record each remainder until you reach 0, then read the remainders from bottom to top. 59 → 111011 → as 8 bits 0011 1011.

Read the remainders from the bottom up: 111011.

Hexadecimal conversions

Why 4 bits per digit: 16 = 24, so each hex digit equals exactly one 4-bit group (a nibble).

Binary → hex: split into 4-bit groups from the right (pad the left group with 0s), convert each. 1011 1110 0001 = BE1.
Hex → binary: write the 4-bit code for each digit. 4 5 A = 0100 0101 1010.
Hex → denary: multiply each digit by its column value and add. 4 5 A = 4×256 + 5×16 + 10 = 1114. C8F = 12×256 + 8×16 + 15 = 3215.
Denary → hex: divide repeatedly by 16, read remainders bottom to top (or convert to binary first).

Why use hex?Shorter and easier for humans to read and remember than binary, and less error-prone
Where hex is usedColour codes in HTML/CSS, MAC addresses, memory addresses and dumps, error messages, debugging, IPv6

8-bit adder

Overflow error: the sum needs a 9th bit, so the stored 8-bit answer is wrong. An 8-bit register holds at most 28 − 1 = 255; 16-bit holds 65 535; 32-bit holds 4 294 967 295.

Overflow example: 01101110 (110) + 11011110 (222). The carry out of the left-most column creates a 9th bit.

Column987654321
Carry11111110
A01101110
B11011110
Sum101001100

The stored 8 bits, 01001100, equal 76, not 332.

Logical binary shifts

Move every bit left or right; the empty places are filled with 0. Each left shift multiplies by 2; each right shift divides by 2 (shift by n gives ×2n or ÷2n). Bits shifted off the end are lost, which can make the result wrong.

OperationResultDenaryEffect
Original0011010153
Left shift 101101010106× 2
Left shift 211010100212× 4
Right shift 10001101026÷ 2 (the lost 1 gives a rounded-down answer)

Two’s complement (positive and negative numbers)

In 8 bits the left-most (most significant) bit has the value −128. Positive numbers start with 0; negative numbers start with 1. To make a negative number: write the positive value in binary, invert every bit, then add 1. Example: −5 → 00000101 → 11111010 → 11111011. Range for 8 bits: −128 to +127.

Check: −128 + 64 + 32 + 16 + 8 + 2 + 1 = −5.

Exam tips: show every working step; give binary answers to the number of bits asked (pad with leading zeros); check additions by converting back to denary; name “overflow” when a 9th bit appears.

Characters are stored in sequence, so “B” follows “A”. Upper and lower case differ by one bit: ‘A’ = 65 (1000001), ‘a’ = 97 (1100001).

Sound

Sound is analogue (continuous). A computer measures (samples) the wave at regular intervals and stores each measurement as a binary number.

Sample rateSamples per second (Hz). Higher rate = closer to the original sound, bigger file
Sample resolutionBits per sample. Higher = more accurate amplitude, bigger file

Telephone call8 000 Hz8 bitsBasic quality, very small
CD music44 100 Hz16 bitsHigh quality, much larger

Why compress? Smaller files need less storage, take less bandwidth, upload/download faster and stream more smoothly.

RLE example

AAAABBBCC becomes 4A3B2C (9 characters stored as 6). RLE works best on data with long runs, such as simple images, and can make random data larger.

Exam tips: state the units you are asked for; remember ÷ 8 (bits → bytes) and ÷ 1024 for each unit step; for compression always say whether data is lost and why that is acceptable.
